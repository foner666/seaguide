# ⚓ SeaGuide

**Образовательный портал для моряков, кадетов и практикантов.**

SeaGuide — структурированная база знаний: выберите профессию и уровень подготовки,
получите подборку учебных модулей именно под вас.

## Возможности

- **4 профессии** — палубная служба, машинная служба, радиоэлектронная служба, общие дисциплины
- **17 учебных модулей** — навигация, COLREG, GMDSS, STCW, MARPOL, судовая медицина и другие
- **Фильтры** — по профессии, аудитории (моряки / кадеты / практиканты) и уровню (базовый / уверенный / продвинутый)
- **Поиск** — по названиям, описаниям и темам модулей
- **Адаптивный дизайн** — работает на телефоне в море и на берегу

## Структура проекта

```
seaguide/
├── index.html      — разметка
├── css/style.css   — стили
└── js/
    ├── data.js     — данные: профессии и учебные модули
    └── app.js      — логика: фильтры, поиск, модальные окна
```

## Как добавить модуль

Откройте `js/data.js` и добавьте объект в массив `MODULES`:

```js
{
  id: "unique-id",
  profession: "deck",        // deck | engine | radio | general
  audiences: ["sailor", "cadet", "intern"],
  level: "basic",            // basic | mid | advanced
  icon: "🧭",
  title: "Название модуля",
  desc: "Краткое описание.",
  topics: ["Тема 1", "Тема 2", "Тема 3"]
}
```

Карточка появится на сайте автоматически. Сделайте `git push` — GitHub Pages обновит сайт сам.

## Сборка и деплой

Сборка не требуется — чистый HTML/CSS/JS. Деплой на GitHub Pages
из ветки `main`, корень — корень репозитория.
